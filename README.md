# TinySteps

TinySteps is a preterm baby follow-up platform for tracking growth, retinal screening, hearing, developmental milestones, vaccines, and care coordination.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set `GEMINI_API_KEY` in `.env.local`
3. Start the development server:
   `npm run dev`

## Build

1. Create a production build:
   `npm run build`
2. Preview the build locally:
   `npm run preview`
